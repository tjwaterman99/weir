## Examples

```text
$ weir service install
Installed /Users/me/Library/LaunchAgents/dev.weir.daemon.plist.
The weir daemon is running and will start again at every login.

$ weir service status
Service installed: /Users/me/Library/LaunchAgents/dev.weir.daemon.plist
Daemon running: idle; last cycle 2m10s ago; next in 2m50s
```

See [keeping mirrors current in the background](../../guides/background.md).
